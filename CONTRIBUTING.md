# Contributing to Foundry Stack

## Setup

1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env`
4. `docker-compose up -d` (PostgreSQL + Redis)
5. `npm run db:migrate`
6. `npm run dev`

## Code Standards

- ESLint + Prettier
- Prisma for DB access
- Conventional commits
- PR reviews required
